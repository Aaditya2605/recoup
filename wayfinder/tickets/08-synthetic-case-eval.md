## Goal

Create one clearly labeled synthetic triple-net retail case with a lease, amendments if needed, reconciliation, ledger, and exact answer key.

## Evaluation

- Extracted terms match the answer key.
- Deadline calculation matches the answer key.
- All planted financial errors are found.
- No false finding survives verification.
- Every finding includes a source quotation, document location, and deterministic calculation.
- The drafted communication contains only verified findings.
- Missing or conflicting evidence produces a failed-closed state.

The synthetic case validates product logic. It does not count as a real customer, payment, landlord action, or Terac submission.
